# Code Audit

Tick an item when it lands, and note the commit next to it.

- P0: broken today, the behaviour is wrong.
- P1: misleading today, users or contributors will get it wrong.
- P2: inconsistent with siblings or other layers, or costly to change.
- P3: polish, duplication, dead code.

## P0: Broken

- [x] 1. `auditor:report --format` default makes `report.format` config dead. `src/Console/Commands/AuditorReportCommand.php:29` declares `{--format=markdown}`, so `:80-81` always sees the string `'markdown'` when omitted and never falls back to `config('laravel-auditor.report.format')`, contradicting `config/laravel-auditor.php:138-140`. Remove the signature default and fall back to config (`Extract Method` parity with the option handling).

## P1: Misleading

- [x] 2. CLI text renderer drops evidence end-lines. `src/Audit/Reports/TextReportRenderer.php:65-70` renders `reference:line` while `src/Audit/Reports/MarkdownReportRenderer.php:180-189` renders `reference:line-endLine`, so `Evidence::file('a.php', 42, 44)` prints `a.php:42` in terminal but `a.php:42-44` in Markdown. Add one shared `Evidence::location()` / `formatReference()` (`Extract Method`) and call it from both renderers.
- [x] 3. `FindingLoader` leaks raw `ValueError`/`TypeError` without file context. `src/Audit/Findings/FindingLoader.php:27-36` catches only `JsonException`, but `Finding::fromArray()` (`src/Audit/Findings/Finding.php:95-97,109`) uses `::from()` and the `array_map` requires `array` items; both commands catch only `RuntimeException` (`AuditorReportCommand.php:61`, `AuditorCiCommand.php:67`). A bad enum string or non-array item surfaces a bare `ValueError` with no path/row, unlike `RuleRegistry::loadFile()/hydrate()` which wraps every failure. Wrap per-item hydration and rethrow `RuntimeException` with path and index.
- [x] 4. `routes`/`models` `collectFiltered()` always marks the payload filtered. `src/Context/Collectors/RoutesCollector.php:49-59` and `src/Context/Collectors/ModelsCollector.php:60-70` forward to the payload builder with `total_count` even for empty or unknown-only arguments (`RoutesCollector.php:96`, `ModelsCollector.php:85-87` ignore unknowns), contradicting `src/Context/FilterableCollector.php:10-12` ("without arguments must return the exact same payload as `collect()`") and disagreeing with the guarded siblings (`DependenciesCollector.php:82-84`, `DatabaseSchemaCollector.php:80-82`). Add the same guard clause (`Introduce Guard Clause`).
- [x] 5. `ModelsCollector` silently drops unresolvable models. `src/Context/Collectors/ModelsCollector.php:196-198` resolves via `$this->app->make($class)`, and `:105-111` swallows the failure, so models with required constructor parameters or booting side effects vanish from the report with no diagnostic. Use side-effect-free instantiation (`ReflectionClass::newInstanceWithoutConstructor`) or record the skip.
- [x] 6. Empty-filter handling diverges between MCP transports. `src/MCP/McpTool.php:117-123` falls back to `collect()` when normalized filters are `[]`, but `src/MCP/Boost/Tools/AuditTool.php:55-61` calls `collectFiltered([])` whenever `$arguments !== []`, so all-`null` filter args return different shapes per transport (`filtered`/`total_count` appear from nowhere over Boost). Extract one shared `resolveFiltered()` policy used by both.
- [x] 7. `McpConfigWriter` reports no-ops as "updated". `src/Support/Agents/McpConfigWriter.php:81-85` (`writeJson`) and `:120-124` (`writeToml`) push to `$updated` when the entry already exists and `!$force`, though nothing is written; `AuditorInstallCommand.php:527-532` renders that bucket as "Up to date". Push to `$skipped` instead, including under `--dry-run`.
- [x] 8. New collector silently missing from Boost. `src/MCP/Boost/BoostMcpRegistrar.php:48-61` hardcodes the 11 tool classes while `src/MCP/McpToolRegistry.php:27-34` auto-discovers via `ContextRegistry::all()`; adding a 12th collector needs edits in the registry, provider, and registrar, and forgetting the last compiles fine. Needs a decision. Derive Boost `toolClasses()` from a single source (collector-to-tool map or tagged discovery).

## P2: Costly to change

- [x] 9. `resourcesTarget()` triplicated verbatim. `src/LaravelAuditorServiceProvider.php:175-180`, `src/Console/Commands/AuditorInstallCommand.php:546-551`, `src/Console/Commands/AuditorStatusCommand.php:106-111` all repeat `trim((string) config('laravel-auditor.resources_target','.ai'),'/\\') ?: '.ai'`. A default/normalisation change must hit three places or `vendor:publish` vs `install` vs `status` drift. Extract one internal resolver (`Extract Method`).
- [x] 10. `AuditorInstallCommand` is oversized with a duplicated skill-tree copy. 560-line class; `prepareStandaloneResources():250-309` and `copySkills():335-367` repeat the same `allDirectories` → `SKILL.md` guard → `relative` → `exists && !force` → `copyDirectory` loop (`:267-287` vs `:344-364`). A `force`/`dry-run` fix in one copy diverges in the other. Extract `copySkillTree()` (`Extract Method`), then an internal installer collaborator (`Extract Class`).
- [x] 11. `AuditorReportCommand` / `AuditorCiCommand` duplicate the report pipeline. `:68-103` vs `:79-112` both build `AuditReport`, `match` over renderer constructors, and branch `file_put_contents` vs `line()`. Adding a format or meta key needs two edits. Extract a shared internal runner (`Extract Class`); renderers stay as-is.
- [x] 12. `relative()` path normaliser copied five times. `ProjectInfoCollector.php:301-315`, `MigrationsCollector.php:126-140`, `SubsystemsCollector.php:121-135`, `McpConfigWriter.php:168-174`, `AuditorInstallCommand.php:553-559` (grep proof). A separator/trailing-slash fix misses four copies. Move one `relativeToBase()` onto `ApplicationPaths` (`Move Method`).
- [x] 13. `created`/`updated`/`skipped` accumulator tuples threaded everywhere. `AuditorInstallCommand.php:250,335,376,402,488,510` and `McpConfigWriter.php:58,108` pass six params and return 2-3 element arrays, mixing by-value returns with by-ref `publishConfig()`. A dropped return assignment loses accounting silently. Introduce an internal `InstallResult` parameter object (`Introduce Parameter Object`).
- [x] 14. `countsByDomain()` omits zero keys while `countsBySeverity()` pre-fills them. `src/Audit/Findings/FindingCollection.php:110-119` (and `RuleRegistry::countsByDomain()`) start from `[]`, but `:93-105` pre-fills all `Severity::cases()` with `0`, so `counts_by_domain` keys vary per run and consumers must `?? 0`. Needs a decision (payload change). Pre-fill from `AuditDomain::cases()` like the severity sibling.
- [x] 15. `DomainRegistry` custom-domain map is incompatible with the enum pipeline. `src/Audit/Domains/DomainRegistry.php:25-28` accepts any custom map, but `Finding::$domain` / `RuleDefinition::$domain` are closed `AuditDomain` enums and renderers parse via `AuditDomain::from()`, so a custom domain crashes Markdown rendering; the provider always registers the default singleton with no config path. Needs a decision. Remove the speculative parameter or wire renderers/status through the registry consistently.
- [x] 16. `McpServer` swallows malformed frames with no Parse error. `src/MCP/McpServer.php:41-45` `continue`s on `json_decode` failure, so a client typo hangs with zero feedback (JSON-RPC `-32700` expected); `respond():158-174` also emits id-less errors and the constructor takes unvalidated `mixed` streams. Emit a Parse error, drop notification responses, and inject a narrow reader/writer (`Dependency Injection`).
- [x] 17. Filter-to-schema mapping duplicated with validation in the wrong home. `src/MCP/McpToolRegistry.php:44-60` and `src/MCP/Boost/Tools/AuditTool.php:36-48` repeat the `foreach ($collector->filters())` loop, and `AuditTool.php:57` reuses stdio-side `McpTool::validateFilters()` (`src/MCP/McpTool.php:50-77`). A schema-shape change needs two hand edits. Move both into a shared filter validator/schema builder (`Extract Class`).
- [x] 18. Service-locator cluster contradicts sibling constructor injection. `MigrationsCollector.php:76` (`app('migrator')`), `AuthorizationCollector.php:131,140-151` (`app('router')`, `app(Gate::class)` despite injectable `?Gate`), `JobsEventsSchedulesCollector.php:137-146` (`app(Schedule::class)` while `Dispatcher` is injected), `DatabaseSchemaCollector.php:96-109` (`DB::`/`config()` with empty ctor), `ProjectContext.php:49` (`config()` helper) — every sibling collector injects `Application`/`Filesystem`/`ApplicationPaths`. Hidden dependencies behave differently per collector on failure. Constructor-inject nullable collaborators (`Replace Service Locator with Injection`).

## P3: Polish

### Duplicates to remove

- [x] 19. Config subdirectory keys flatten lossily. `src/Context/Collectors/ConfigurationCollector.php:44-50` uses `pathinfo($file, PATHINFO_FILENAME)` as root while `configFiles():66-78` returns subdirectory-relative pathnames, so `config/nested/file.php` advertises `file.*` instead of `nested.file.*` with cross-directory collisions. Derive the root from the relative path (strip `.php`, `/` to `.`).
- [x] 20. `models[].timestamps` key is unstable. `src/Context/Collectors/ModelsCollector.php:200-216` always sets `'timestamps'` then `unset()`s it when false (calling `usesTimestamps()` twice), so consumers cannot rely on the key. Always emit the boolean (`Preserve Whole Object`).

### Dead code

- [x] 21. `BoostDetector::supportsThirdPartyResources()` has no production callers. `src/Support/BoostDetector.php:30-36`; grep finds only the definition plus `tests/Feature/BoostTest.php` stubs. Trivial `isInstalled()` wrapper with a vague "since v0.x" comment. Delete it or wire it into the registrar/installer.
- [x] 22. `Evidence::dependency()` drops `$version` when `$detail` is present. `src/Audit/Evidence/Evidence.php:55-58` collapses both into one slot (`$detail ?? $version`); no in-repo caller passes both today, so polish. Keep both (e.g. `metadata['version']`) or reduce to one documented parameter.

### Behaviour edges

- [x] 23. Config files are `require`d inside a "safe read-only" collector. `src/Context/Collectors/ConfigurationCollector.php:91-92` executes application config files though `src/Context/ContextCollector.php:23-28` promises safe read-only collection; throws are swallowed to `[]` but `exit`/side effects are not. Read via the config repository instead (`Move Method`).
- [x] 24. Install/report/context accounting edges. `AuditorReportCommand.php:54-56` lets `--example` silently overwrite explicit `--findings`; dry-run vs real-run config summaries differ (`AuditorInstallCommand.php:479-503`); `AuditorContextCommand.php:63` encodes outside its `try` so `JsonException` escapes uncaught. Reject conflicting options, separate accounting from writing, and wrap the encode like the `collect()` path.
